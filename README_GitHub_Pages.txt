FABITO_BLM — GitHub Pages setup

This is a static website package for GitHub Pages. It includes index.html and the product images.

Publish from an iPhone:
1. Sign in or create a free account at https://github.com
2. Create a new repository named fabito-blm-store.
3. Set the repository to Public.
4. Choose Add file > Upload files.
5. Upload index.html and every front_*.jpg and back_*.jpg image from this folder. Do not upload the ZIP itself.
6. Commit the files to the main branch.
7. Open repository Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Choose branch main and folder /(root), then Save.
10. Wait a few minutes for the Pages URL shown on Settings > Pages.
